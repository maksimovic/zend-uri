# maksimovic/zend-uri

A PHP 8.1+ compatible fork of [zf1s/zend-uri](https://github.com/zf1s/zend-uri), originally from [Zend Framework 1](https://github.com/zendframework/zf1).

URI manipulation and validation, with support for HTTP and HTTPS URI schemes.

## Installation

```bash
composer require maksimovic/zend-uri
```

This package replaces `zf1/zend-uri` and `zf1s/zend-uri`.
